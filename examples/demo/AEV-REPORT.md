# Agentic Earned Value (AEV) report

As of **2026-02-09** for `example/demo-project`. Calculated with the [AEV method note v0.1](https://github.com/GunpreetSabharwall/agentic-earned-value/blob/main/AEV-method-note-v0.1.md).

**What this means:** For every $1 spent, the project has earned $1.00 of value; it is on budget and behind schedule. 11.1% of the work that was marked done did not stick and was taken back.

## Summary

| Indicator | Value | Meaning |
|---|---:|---|
| Budget at Completion (BAC) | $100,000 | Total planned budget |
| Planned Value (PV) | $50,000 | Value planned to be done by now |
| Earned Value (EV) | $40,000 | Value of accepted work that stuck |
| Actual Cost (AC) | $40,000 | People + review + agent spend so far |
| CPI = EV / AC | 1.00 | Below 1.00 = over budget |
| SPI = EV / PV | 0.80 | Below 1.00 = behind schedule |
| EAC = AC + (BAC − EV) / CPI | $100,000 | Forecast total cost |

## Classic EVM vs. AEV

Classic EVM counts only build labor and never takes value back. AEV adds review and agent costs and claws back work that did not stick.

| Indicator | Classic EVM (labor only, no clawback) | AEV |
|---|---:|---:|
| EV | $45,000 | $40,000 |
| AC | $30,000 | $40,000 |
| CPI | 1.50 | 1.00 |
| SPI | 0.90 | 0.80 |
| EAC | $66,667 | $100,000 |

## New AEV indicators

| Indicator | Formula | Value | What it tells you |
|---|---|---:|---|
| Rework Rate | Clawback / Gross EV | 11.1% | Share of "done" work that did not stick |
| Agent Cost Share | AC_agent / AC | 10.0% | How much of spend goes to agents |
| Review Load Ratio | AC_review / AC_agent | 1.50 | $1.50 of human review per $1 of agent spend |

## Assumptions

- Planned value grows in a straight line from 2026-01-05 to 2026-03-16.
- Hourly rate: $100. Stabilization window: 14 days.
- Agent accounts: `aev-agent-bot`.
- Hours and agent costs are entered by hand in `.aev/hours.csv` and `.aev/agent-costs.csv`. Review time is self-reported.
